# SEMBULUNG NAVIGATOR

Android shell project for the SEMBULUNG NAVIGATOR rebrand and device-bound activation system.

- Application ID: `com.sembulung.navigator`
- Branding: SEMBULUNG NAVIGATOR / BY WONG MBRAYU
- Activation: one device code = one signed activation key
- Private activation key and release keystore are **not stored in this repository**.
- Current development: V8 waypoint and route module.

This repository intentionally contains only the clean shell/rebrand/activation layer. It does not include the previously inspected patched Boating binary or any subscription bypass code.
